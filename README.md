# 💈 ЧИО ЧИО — Экспресс-парикмахерская (Chio Chio Express Barbershop)

Веб-приложение и электронный терминал самообслуживания для экспресс-парикмахерской в фирменном черно-бело-красном стиле «Чио Чио».

---

## 🚀 Основные возможности

### 1. 📱 Клиентский терминал оплаты после стрижки
* **Регистрация / авторизация по номеру телефона**: удобная маска ввода `+7 (9XX) XXX-XX-XX`.
* **Автоматическая проверка визитов**: система проверяет историю клиента и отображает интерактивную карту лояльности.
* **🎁 Каждая 3-я стрижка — БЕСПЛАТНО (скидка 100%)**:
  * 1-й визит — стандартная оплата;
  * 2-й визит — стандартная оплата;
  * **3-й визит — 0 ₽ (Бесплатно)**! Применяется автоматическая скидка 100%, запускается поздравительная анимация и звуковой фанфар.
  * После 3-го визита цикл повторяется (каждая третья стрижка бесплатна).
* **Выбор стрижки и мастера**: карточки услуг с длительностью и ценами, карточки мастеров с фото, рейтингом и специализацией.
* **Способы оплаты**:
  * СБП (динамический QR-код для банковских приложений);
  * Банковская карта (виртуальный терминал);
  * Наличные (купюроприемник терминала).
* **Электронный чек с печатью**: отображение номера чека, разбивки сумм, штампов лояльности и кнопки печати.

---

### 2. ✂️ Справедливое распределение 50 / 50 в пользу мастера
* Клиент после стрижки выбирает мастера, который его подстригал.
* **50% от суммы стрижки мгновенно зачисляется на персональный баланс мастера**:
  * Например, при стрижке за 600 ₽: **300 ₽ мастеру** и **300 ₽ салону**.
* **При бесплатной 3-й стрижке**: салон субсидирует мастеру 50% от номинальной стоимости стрижки, поэтому мастер не теряет в доходе за лояльных клиентов.

---

### 3. 🛡️ Панель Администратора (Вход по логину и секретному ключу)
* **Данные для входа**:
  * **Логин**: `admin`
  * **Секретный ключ**: `chio2026`
* **Финансовая аналитика в реальном времени**:
  * Общая выручка (оборот);
  * Доля мастеров (начисленные 50%);
  * Чистый доход салона (50%);
  * Количество выполненных стрижек (всего и за сегодня);
  * Количество подаренных бесплатных стрижек по акции.
* **Управление мастерами**:
  * Добавление мастера (ФИО, специализация, телефон, фото);
  * Просмотр баланса каждого мастера;
  * Функция **«Выплатить 50%»** с фиксацией в журнале выплат.
* **Управление стрижками и прайс-листом**:
  * Добавление новой стрижки (название, цена в рублях, длительность в минутах, описание);
  * Редактирование и деактивация услуг.
* **Журнал чеков**: подробная история по каждой стрижке с указанием 50% доли мастера и 50% доли салона.
* **База клиентов**: список номеров, счетчик стрижек, статус до следующей бесплатной.

---

### 4. 👤 Личный кабинет мастера
* Мастер может выбрать свое имя и просматривать:
  * Баланс к выплате на текущий момент;
  * Заработок за сегодняшнюю смену;
  * Суммарный заработок за все время;
  * Историю своих стрижек с точной суммой 50%.
